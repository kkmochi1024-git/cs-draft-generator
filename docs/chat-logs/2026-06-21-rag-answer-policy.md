# RAGに登録されていない情報への回答方針

- **日時**: 2026-06-21
- **参加者**: ユーザー, Claude

## 背景・目的

プロトタイプの動作確認中に、RAGに登録されていない内容（LLMの学習済み知識で回答可能な質問）に対して回答が得られないことが判明。LLMの知識を活用すべきかの設計判断を行う。

## 議論の要点

### RAG未登録情報への回答可否

- **ユーザーの質問**: RAGに登録されていない内容はLLMが学習済みでも回答不可能か？
- **AIの回答**: 現在の実装ではシステムプロンプトで「参考情報に含まれない内容については確認いたします」と指示しているため、LLMは自身の知識があっても回答を拒否する。これは意図的な設計
- **結論**: カスタマーサポート用途では現状のRAG限定のままとする

### RAG限定にしている理由

1. 根拠のない回答を生成させないことが重要（LLMの学習知識は製品固有の仕様と異なる可能性がある）
2. RAGの参照元を明示できるため、担当者が回答の正確性を検証できる
3. 誤った回答を顧客に送るリスク > 回答できないリスク

### LLM知識を活用する場合の代替案（却下）

システムプロンプトを「参考情報に基づかない回答には『※一般的な情報です』と付記してください」に変更すれば対応可能。ただしカスタマーサポート用途では非推奨のため不採用。

## 決定事項

- システムプロンプトは変更しない（RAGに登録されたデータのみで回答する現行方針を維持）
- 将来的にLLM知識の活用が必要になった場合は、`config.py` の `SYSTEM_PROMPT` を変更するだけで対応可能
