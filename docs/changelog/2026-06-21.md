## 変更概要

- **変更日時**: 2026-06-21
- **変更対象**: `src/masking/service.py`
- **変更種別**: 更新
- **変更カテゴリ**: バグ修正
- **変更理由**: `docker compose exec -it` のtty環境で日本語を入力した際、`UnicodeEncodeError: 'utf-8' codec can't encode characters in position 2-3: surrogates not allowed` が発生する問題の修正

## 変更前

- `MaskingService.mask()` に入力テキストのサニタイズ処理なし
- Docker pty経由の日本語入力でサロゲート文字が混入した場合、SudachiPy（GiNZAのトークナイザ）が内部でUTF-8エンコードする際にクラッシュ

## 変更後

- `MaskingService.mask()` の冒頭で `text.encode("utf-8", errors="surrogateescape").decode("utf-8", errors="replace")` を実行し、サロゲート文字を安全に除去する処理を追加
- Docker tty環境での日本語入力が正常に処理されるようになった

## 影響範囲

- `mask` / `register` / `ask` / `chat` の全コマンドでDocker tty経由の日本語入力が安定動作するようになった
