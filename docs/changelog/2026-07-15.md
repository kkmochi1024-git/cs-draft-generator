# 変更ログ: 2026-07-15（2件目）

## 変更概要

- **変更日時**: 2026-07-15
- **変更対象**:
  - `src/masking/service.py`（更新）
  - `tests/test_masking.py`（更新: テスト2件・スタブ1クラス追加）
  - `settings/detailed-design/01-masking.md`（更新）
- **変更種別**: 更新
- **変更カテゴリ**: バグ修正
- **変更理由**: 詳細設計書レビュー（同日1件目のログ「付随して発見した課題」1）で発見された PII マスク漏れバグの修正。同一の固有表現（例: 同じ人名）がテキスト中に複数回出現すると、2回目以降がマスクされないまま LLM に渡り（PII漏えい）、マスクトークンも破損していた。

## 変更前

- `MaskingService._map_ner_to_original` は各NERエンティティを常にテキスト先頭から `find()` で検索し、正規表現エンティティの範囲としか重複チェックしなかった。そのため同一文字列のNERエンティティが複数ある場合、全てが最初の出現位置に重複マッピングされ、`mask()` の置換で同一範囲に多重置換が発生（例: `"山田太郎です。山田太郎さんによろしく。"` → `"[Person_2]son_1]です。山田太郎さんによろしく。"`）

## 変更後

- 占有範囲集合 `occupied` を正規表現エンティティで初期化し、NERエンティティをマッピングするたびに採用した範囲を `occupied` へ追加する方式に変更。同一文字列の2回目以降は次の出現位置に対応付く（同例 → `"[Person_1]です。[Person_2]さんによろしく。"`、unmask で完全復元）
- 回帰テスト2件を追加（`test_mask_duplicate_ner_entity`: GiNZA非依存の `_StubNer` による end-to-end 検証、`test_map_ner_duplicates_to_distinct_positions`: 位置マッピングの単体検証）
- `settings/detailed-design/01-masking.md` の「既知の制限（実装バグ）」記載を削除し、修正後の挙動（占有集合方式）と回帰テストへの参照に更新

## 影響範囲

- `MaskingService.mask()` を利用する全経路（CLI `mask`/`register`/`ask`/`chat`、WebUI の登録・チャット、`IndexService`/`QueryService`）のマスキング精度が向上。既存の単一出現ケースの挙動は不変
