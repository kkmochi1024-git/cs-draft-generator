## 変更概要

- **変更日時**: 2026-06-17

- **変更種別**: 更新
- **変更カテゴリ**: 設計変更
- **変更理由**: ユーザーの要求により、マスキング機能を単独でも利用できるようモジュールをサービスインターフェースで分離する設計に変更

## 変更前

- 全機能がCLIエントリポイント(main.py)から直接呼び出されるモノリシックな構成
- マスキングを単独で使うCLIコマンドなし
- ファイル名: `pipeline.py`、`indexer.py`、`chain.py`

## 変更後

- **サービスインターフェース導入（セクション2.2, 4）:**
  - `MaskingService`（単独利用可・外部依存なし）、`IndexService`、`QueryService` の3サービスに分離
  - 各サービスは依存性注入でコンストラクタ経由で結合（疎結合）
  - 将来マイクロサービス化する際にHTTP APIへの切り出しが最小変更で可能な設計
- **マスキング単独モード追加（セクション3.1）:**
  - `main mask` コマンドでRAGやLLMを使わずマスキングのみ実行可能
  - テキスト直接指定・標準入力パイプに対応
- **ディレクトリ構成変更（セクション5）:**
  - `masking/pipeline.py` → `masking/service.py` + `masking/regex_masker.py` + `masking/models.py` に分割
  - `rag/indexer.py` → `rag/index_service.py`、`rag/chain.py` → `rag/query_service.py` にリネーム
  - `rag/models.py`（RegisterResult, AnswerResult）を新設
  - テストファイルもサービス単位に分割（`test_masking.py`、`test_index.py`、`test_query.py`）

## 影響範囲
